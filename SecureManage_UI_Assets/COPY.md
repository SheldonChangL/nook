# SecureManage 登入文案

## 建議版本
- 左側標題：歡迎回來
- 左側說明：你的敏感資料，只留在這台裝置。
- 右側標題：歡迎回來
- 右側副標：輸入主密碼以進入 SecureManage
- 欄位：主密碼
- 按鈕：進入 SecureManage
- 提示：若遺失主密碼，將無法取回已加密的資料。

## 三個賣點
- 本機儲存 — 資料不離開這台裝置
- AES-256 加密 — 敏感資料以強加密保護
- 無雲端同步 — 不會自動上傳任何內容

## 不建議
- 解鎖保險庫：太像密碼管理器或金融保管箱，且「保險庫」容易讓人覺得過度戲劇化。
- 解除鎖定並進入 SecureManage：太長，按鈕像系統設定而不是登入。
